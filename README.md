# cpp.projects

A collection of my C++ projects and small applications built to practice core language fundamentals, memory management, and graphics programming.

## Projects

* **[`basic-clicker-game`](./basic-clicker-game)** — A 2D clicker game built with C++ and raylib featuring upgrade scaling, basic UI states, and a 1,000,000,000-click win condition.

## Prerequisites

* A C++17 (or newer) compiler such as `g++`
* [raylib](https://raylib.com) installed for graphical projects

## Getting Started

Clone the repository and navigate into any project directory for build and run instructions:

```bash
git clone https://github.com
cd cpp.projects
```
